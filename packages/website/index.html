02 — features

Built for real environments.

Mixed installs happen. PATH drift happens. kitup updates the tool you are actually invoking.

01

PATH-aware

Updates the binary on your PATH, not a random duplicate. Multi-install detection comes standard — when a tool exists twice, kitup tells you which one wins and why.

02

One command

kitup update --all, or pick tools individually. Dry-run previews every change before anything is touched.

03

Cross-platform

macOS (Apple Silicon + Intel), Linux, Windows. A single ~9MB binary with zero runtime dependencies.

04

Interactive TUI

A lazygit-style dashboard: select tools, preview versions, update in parallel — all without leaving the keyboard.

✳

More with every release

kitup is under active development — new tools and adapters land regularly.
05

Provider management

Switch API providers for Claude, Codex, and Gemini with circuit-breaker failover. Configs are backed up on every switch, and the change is persisted where each tool actually reads it.

06

Health diagnostics

kitup doctor checks network connectivity, flags multi-installs, and can auto-fix configuration issues.
